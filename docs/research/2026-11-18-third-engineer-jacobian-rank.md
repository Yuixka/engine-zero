# Third-engineer experiment: local constraint-rank gate (2026-11-18)

**Observed gap:** The main solver uses the generic planar mobility count and sampled closure residuals. These do not establish local independence of the constraints: a graph with the expected equation count can be underconstrained at particular poses. A numerical Jacobian rank check provides an independent *structural diagnostic* (although it reuses the solver's analytic Jacobian, so is not an independent geometry verification).

**Falsifiable hypothesis:** For synthetic mechanisms with deliberately dependent constraint rows, this audit reports nonzero rank deficiency, while a nondegenerate single-crank graph is full column rank across 24 poses. Negative controls include exact and near-dependent matrices. Benchmark next: compare baseline accepted candidate counts against candidates rejected by this gate over 20 frozen random seeds and 36/144 sampled phases, then independently confirm flagged cases by finite-difference Jacobians and perturbation/continuation tests. A failure to detect injected dependencies, or false rejection of valid well-conditioned cases, falsifies the utility claim.

**Method:** Per-column scale the analytic constraint Jacobian, use twice-reorthogonalized row-pivoted Gram-Schmidt, and report rank relative to a configurable threshold. No new dependencies. This is a heuristic; the reported pivot magnitude is **not** a singular value or condition number. Local full rank is neither proof of global mobility nor a guarantee against inter-sample singularities. No dynamics, loads, 3D CAD, or manufacturing physics.

**Prior art:** Constraint-Jacobian rank, singularity analysis, and mechanism mobility theory are established mathematical/mechanical engineering practice (see e.g. standard multibody kinematics literature and the established modeling capabilities of OpenModelica and Project Chrono). This implementation is a safety/verification increment, **not a new invention**. A future potentially differentiating claim requires independently validated *closed-loop* robust topology generation and verification against fair baselines, not rank checking alone.

**Reproduce:** `node experiments/test-jacobian-rank-audit.js`; run `node test.js` and GitHub CI. Execution results must be recorded separately; this document does not claim tests ran.
